# Task Tracker

Task Tracker is a simple console application built with C# Basics.

The project works like a basic To-Do List where the user can manage daily tasks through a simple menu.

## Features

- Add a new task
- View all tasks
- Mark a task as completed
- Delete a task
- Exit the application

## Technologies

- C#
- .NET Console Application

## C# Concepts Used

- Variables
- Arrays
- Methods
- Loops
- If Statements
- Switch Statements
- User Input
- int.Parse()
- Static Methods

## How It Works

When the application starts, the user enters their name.

Then a menu appears with multiple choices:

1. Add Task
2. Mark Task as Completed
3. View Tasks
4. Delete Task
5. Exit

The user can add tasks for the day, view them, mark completed tasks, or remove tasks.
